=====================================================================
 คู่มือตั้งค่า Gemini API Key สำหรับหน้า "แนะนำโดย AI"
 (ไฟล์นี้ปลอดภัย ไม่มีคีย์จริงอยู่ในนี้ ขึ้น GitHub ได้ตามปกติ)
=====================================================================

ทำไมต้องตั้งค่าเอง ทำไมไม่ฝังคีย์มาในโปรเจคเลย?
---------------------------------------------------------------
เพราะ API key เป็นความลับเฉพาะคน ถ้าฝังไว้ในโค้ดแล้ว push ขึ้น GitHub
Google จะสแกนเจอและ "ยกเลิกคีย์ทันที" (revoke) แอปจะต่อ AI ไม่ได้เลย
วิธีที่ถูกต้องคือแต่ละคน/แต่ละเครื่องตั้งคีย์ของตัวเองไว้ในไฟล์
local.properties ซึ่งไฟล์นี้ถูกกันไม่ให้ขึ้น GitHub อยู่แล้ว
(ดูใน .gitignore บรรทัด local.properties)

หมายเหตุ: ถ้าไม่ตั้งค่าตามคู่มือนี้เลย แอปก็ยังใช้งานได้ปกติทุกฟีเจอร์
เพียงแต่หน้า AI จะสลับไปค้นหาจากเมนูในเครื่องแทน (โหมดออฟไลน์)


ขั้นตอนที่ 1 — ขอ API Key ฟรีจาก Google
---------------------------------------------------------------
1. เข้าเว็บ https://aistudio.google.com/apikey
2. ล็อกอินด้วย Google Account (ใช้ของใครก็ได้ในทีม)
3. กด "Create API key" เลือกสร้างใน project ใหม่ หรือ project ที่มีอยู่
4. คัดลอกคีย์ที่ได้เก็บไว้ (คีย์จะขึ้นต้นด้วย "AIza...")

*** คำเตือนสำคัญ ***
ห้ามเปิด "Cloud Billing" ผูกกับ Google Cloud project เดียวกับที่ใช้
ทดสอบฟรีนี้เด็ดขาด เพราะจะทำให้ free tier หายไปทันที คิดเงินตั้งแต่
token แรก ถ้าอยากทดสอบแบบเสียเงินให้แยกสร้าง project ใหม่ต่างหาก


ขั้นตอนที่ 2 — หาไฟล์ local.properties ในโปรเจค
---------------------------------------------------------------
ไฟล์นี้ Android Studio สร้างให้อัตโนมัติอยู่แล้วตั้งแต่เปิดโปรเจค
ครั้งแรก อยู่ที่ root ของโปรเจค (ระดับเดียวกับ build.gradle,
settings.gradle, gradlew)

ถ้ามองไม่เห็นไฟล์นี้ในแถบไฟล์ทางซ้าย:
  - แถบ Project panel ทางซ้ายมี dropdown เขียนว่า "Android"
  - เปลี่ยนเป็น "Project" แทน จะเห็นไฟล์ทุกตัวตาม path จริง

หน้าตาไฟล์เดิม (Android Studio สร้างให้) จะประมาณนี้:

    ## This file must *NOT* be checked into Version Control Systems,
    # as it contains information specific to your local configuration.
    #
    # Location of the SDK. This is only used by Gradle.
    # For customization when using a Version Control System, please
    # read the header note.
    #Sun Sep 07 12:00:00 ICT 2026
    sdk.dir=C\:\\Users\\ชื่อคุณ\\AppData\\Local\\Android\\Sdk


ขั้นตอนที่ 3 — เพิ่มคีย์เข้าไปในไฟล์
---------------------------------------------------------------
คลิกท้ายบรรทัดสุดท้าย (บรรทัด sdk.dir=...) กด Enter ขึ้นบรรทัดใหม่
แล้วพิมพ์ต่อท้ายแบบนี้ (แทนที่ข้อความในวงเล็บด้วยคีย์จริงของคุณ):

    GEMINI_API_KEY=<วางคีย์ที่ได้จาก aistudio.google.com ตรงนี้>

ตัวอย่างผลลัพธ์สุดท้าย (คีย์ในตัวอย่างนี้เป็นของปลอมนะ อย่าเอาไปใช้):

    ## This file must *NOT* be checked into Version Control Systems,
    # as it contains information specific to your local configuration.
    #
    # Location of the SDK. This is only used by Gradle.
    # For customization when using a Version Control System, please
    # read the header note.
    #Sun Sep 07 12:00:00 ICT 2026
    sdk.dir=C\:\\Users\\ชื่อคุณ\\AppData\\Local\\Android\\Sdk
    GEMINI_API_KEY=AIzaSyD1234567890ตัวอย่างเท่านั้นห้ามใช้จริง

ข้อควรระวังตอนพิมพ์:
  - ห้ามมีช่องว่างรอบเครื่องหมาย "="
  - ห้ามใส่เครื่องหมายคำพูดครอบคีย์ (ไม่ต้องมี " ครอบ)
  - วางคีย์ให้อยู่บรรทัดเดียว ห้ามตัดขึ้นบรรทัดใหม่กลางคีย์


ขั้นตอนที่ 4 — Sync แล้วรันใหม่
---------------------------------------------------------------
1. กด Ctrl+S เซฟไฟล์ local.properties
2. กด File > Sync Project with Gradle Files (ไอคอนช้างมีลูกศรวน)
3. รอ sync เสร็จ แล้วกด Run เปิดแอปใหม่
4. เข้าหน้า "แนะนำโดย AI" พิมพ์คำถาม เช่น "อยากกินเผ็ด ๆ ทำเร็ว"
   ถ้าเชื่อมสำเร็จจะเห็นผลลัพธ์จาก Gemini จริง ไม่ใช่ข้อความ
   "โหมดออฟไลน์" เหมือนก่อนหน้านี้


คีย์ต้องใส่ใหม่ทุกครั้งไหม?
---------------------------------------------------------------
ไม่ต้องครับ ใส่ครั้งเดียวแล้วอยู่ถาวรในเครื่องนั้น (ฝังเข้า BuildConfig
ตอน build) ต้องใส่ใหม่เฉพาะตอน:
  - clone โปรเจคมาเครื่องใหม่ (ไฟล์นี้ไม่ติดมาด้วยเพราะถูก gitignore)
  - เพื่อนอีกคนเปิดโปรเจคบนเครื่องของเขาเอง (แต่ละเครื่องต้องมีไฟล์
    นี้ของตัวเอง)


ทีม 5 คนใช้คีย์เดียวกันยังไง?
---------------------------------------------------------------
ส่งคีย์จริงให้กันทาง แชทส่วนตัวของทีม (Line/Discord) เท่านั้น
ห้ามพิมพ์คีย์จริงลงไฟล์ไหนก็ตามที่อยู่ใน repo นี้แล้ว commit ขึ้น
GitHub เด็ดขาด ไม่ว่าจะตั้งชื่อไฟล์ว่าอะไรก็ตาม (git ไม่สนใจชื่อไฟล์
หรือนามสกุล ไฟล์ไหนถูก commit คีย์ในไฟล์นั้นก็หลุดเหมือนกันหมด)
ที่ local.properties ปลอดภัยเพราะมันถูกระบุชื่อไว้ใน .gitignore
ไม่ใช่เพราะชื่อไฟล์พิเศษอะไร
